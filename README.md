# The Digital Detective 🔍

**Diwali Independent Learning Assignment — Explore Your Computer • Build a Mini System Report**

In this project I investigate how my computer works: how it takes input and produces output, how the Terminal and
operating system manage files and programs, how numbers and text are stored as bits, how Git and GitHub keep track of
work, and how computers talk to each other over a network.

The work is split into **missions**. Each mission lives in its own folder with its own `README.md`, and each mission
was completed, documented, committed and pushed separately before starting the next one.
