### Task 1.1 — Trace one activity using IPOS
**Activity:** typing my assignment notes in a text editor and saving them.

| Stage | What happens in my example | Hardware / component |
|-------|----------------------------|----------------------|
| Input | I press keys on the keyboard and click with the trackpad to place the cursor. Each key press is sent to the computer as a signal. | Keyboard, trackpad |
| Processing | The CPU receives the key codes, the editor program decides which character to insert, and the text is held in RAM while I work. | CPU (Apple M-series chip), RAM |
| Output | The new letters appear on the screen almost instantly, so I can see what I typed. | Display (screen), graphics part of the chip |
| Storage | When I press **Cmd + S**, the text in RAM is written to a file so it stays after the laptop is turned off. Later I also push it to GitHub. | Internal SSD, cloud storage (GitHub) |
| Extra: Output again | After saving, the window title changes to show the file is saved — this is feedback to me. | Display |

**How it flows:** My key presses (input) are turned into data that the CPU works on using RAM (processing). The result is
shown straight away on the screen (output). RAM is temporary and is cleared when power goes off, so saving copies the
data to the SSD (storage). When I open the file later, the data travels back from storage into RAM and onto the screen.

## 4. My understanding
Every computer, from a laptop to an ATM, follows the same pattern: it gets **input**, **processes** it with a
processor, gives **output**, and **stores** what needs to be kept. Hardware is the physical part I can touch; software is
the set of instructions that tells the hardware what to do. Software itself has types: the **operating system** runs the
whole machine, **applications** help me do my own tasks, and **utilities** keep the computer healthy. I also learned
that RAM is temporary while the SSD is permanent, which is why saving a file matters.

## 5. Difficulties faced
At first I was not sure whether a web browser should be "utility" or "application" software.

## 6. How I resolved them
I compared it with the definitions: a browser helps the *user* do a task (browsing), so it is application software. A
utility like Disk Utility helps look after the *computer* itself.
